# RaceDay - Race Management System

## System Overview
RaceDay is an event management platform designed to streamline race registrations, category management, participant enrolments, and race finish-time tracking.

## User Roles
* **Organiser:** Responsible for creating events, defining race categories, monitoring participant enrolments, and logging final completion times and ranks.
* **Participant:** Responsible for registering an account, browsing available events, enrolling in preferred race categories, and viewing race results.
